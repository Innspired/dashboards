# 📊 Проектирование системы отчётности (BI Dashboards)

Репозиторий с моими учебными кейсами, выполненными в рамках курса **«Продвинутая аналитика данных»** от **Karpov.Courses**. 

Здесь представлен полный цикл работы над отчётностью: от анализа бизнес-требований и проектирования архитектуры (Dashboard Map) до детального дизайна и реализации (Dashboard Canvas & Dashboard).

## 📖 Теоретическая база
Методология, использованная в проектах, опирается на фреймворки визуализации данных и продуктового подхода к BI, описанные в книге **Романа Бунина** ([«От дашборда к системе: как построить аналитику в компании»](https://datalens.ru/book/intro.html)). Отдельная благодарность Роману, как преподавателю курса, за структурированные материалы, практические примеры и интересные задания!

## 🗂 Структура репозитория

*   **[`dashboard_map/`](./dashboard_map/)** — Кейс по проектированию архитектуры системы отчётности для B2C-отдела. 
    *   *Что внутри:* Анализ стратегической сессии, выделение ролей и процессов, мэтчинг с типами дашбордов (Овервью, Self-service, Алерты) и приоритизация.
    *   *Инструмент:* Holst.
*   **[`dashboard_canvas_and_dashboard/`](./dashboard_canvas_and_dashboard/)** — Кейс по разработке конкретного дашборда для команды листинга.
    *   *Что внутри:* Интервью с заказчиком, заполнение Dashboard Canvas, реализация интерактивного дашборда с учётом особенностей неаддитивных данных.
    *   *Инструменты:* Holst (макет), Yandex DataLens (реализация).
*   **`assets/`** — Вспомогательные материалы.

## 🚀 Как смотреть кейсы
Каждая папка содержит свой файл `case_description.md` с подробным описанием задачи, процесса и результата. Внутри также лежат исходные данные, PDF-макеты и ссылки на интерактивные материалы (доски и дашборд).
