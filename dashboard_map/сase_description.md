# Кейс: Проектирование системы отчётности (Dashboard Map)

## 🎯 Задача
Разработать архитектуру системы отчётности (Dashboard Map) для B2C-отдела. На входе была запись стратегической сессии с заказчиками и список ролей/бизнес-процессов. Цель — связать потребности пользователей с конкретными типами дашбордов.

## 🛠 Что было сделано
1. **Анализ записи сессии:** Выделила 10 ключевых ролей и их запросы к данным.
2. **Структурирование сущностей и процессов:** Определила основные бизнес-процессы и их точки контроля.
3. **Мэтчинг:** Использовала алгоритм «Подразделение → Сущность → Процесс → Тип дашборда».
   * Для подразделений — *Овервью* и *Self-service*.
   * Для продуктов/каналов — *Страницы сущностей*.
   * Для **процессов и точек контроля** — *Алерты* (оперативное реагирование на отклонения) и *Аналитические дашборды* (поиск причин и инсайтов, например, для Воронки продаж и Unit-экономики).
4. **Аргументация:** Для каждого дашборда написала краткое обоснование (зачем он нужен и какую боль заказчика закрывает).

## 🧰 Инструменты
**Holst** - сервис онлайн-досок для визуализации и совместной работы
  
## 📈 Результат
* Создана **Dashboard Map**, включающая все роли и процессы.
* Сформирован **Action Plan** (таблица приоритетов с ответственными и заказчиками).
